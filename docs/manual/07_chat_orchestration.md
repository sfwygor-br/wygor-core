# Wygor Core - Manual do Chat Orquestrador

## 💬 Interactive Chat & Workflow Execution
O chat interativo (`wygor chat`) unifica a comunicação por linguagem natural com a orquestração de ferramentas locais.

### Comandos de Atalho:
- `/workflow <tarefa>`: Executa a orquestração ponta a ponta (Git Prepare -> Context -> Code -> Check -> Commit).
- `/git prepare <task>`: Isola o workspace em uma nova branch.
- `/git commit <mensagem>`: Salva o progresso localmente.
- `/check [comando]`: Executa linters e testes do projeto.
